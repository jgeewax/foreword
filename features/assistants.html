FeaturesThe assistant

Bring the assistant you already use

Foreword doesn’t come with an AI of its own. It works with one you may already pay for (OpenCode, Claude Code, Codex, Gemini CLI or Antigravity), signed in with your own account, and turns it from a coding assistant into a writing one. There’s no new subscription.

The five

OpenCode
Open source. Works with any AI you’ve set it up for: OpenAI’s, Anthropic’s, Google’s, or one that runs on your Mac. It comes inside Foreword, so there’s nothing else to install, but it still needs an AI to talk to.
Claude Code
Anthropic’s. Claude, with your Claude plan or an API key.
Codex
OpenAI’s. Its models, with your ChatGPT plan or an API key.
Gemini CLI
Google’s. Gemini, with a paid API key or a Gemini Code Assist work account. It stopped taking personal Google accounts in June 2026.
Antigravity
Google’s newer one: Gemini and more, with your Google account, a Gemini API key or Gemini Enterprise. Settings downloads what it needs from Google the first time.

Settings ▸ Assistant shows where each one stands: Installed, Signed in with ChatGPT, Not signed in, Needs Node.js. To sign in, Sign in in Terminal opens Terminal with the sign-in already started, and a note saying what to do. Come back to Foreword when you’re done and the assistant starts up on its own.

Whichever you choose, everything else on these pages works the same way: tasks, modes, questions, permissions, the account of what it did.

What Foreword changes

These assistants are built for writing software, and left to themselves they behave that way: they try to build the book, write scripts, and report their work as a programmer would. Foreword gives each one:

  • Instructions for a book, not a codebase. One sentence per line. Leave the typesetting to the preview. Say what changed in one to three sentences. Write maths as Typst maths. Don’t build tools around the book.
  • Your book’s style guide, in every conversation.
  • Foreword’s own modes: Write, Ask, Discuss, Options and Figures, enforced by Foreword.
  • The same question panel for all five, however each one likes to ask.
  • Every step in words about your book.
  • Your permissions, kept by Foreword, the same for every assistant.
  • A way to change Foreword’s settings, its model or which assistant it is, when you ask it to.

Model and effort

Under the message box: the assistant, the model, and how hard it thinks. Effort is how long the model thinks before it answers. More is slower, and usually better on hard requests. It matters about as much as the choice of model, so it has its own menu. Claude Code has Default, Low, Medium, High, Extra high and Max. Codex and OpenCode have their own levels. Foreword remembers the level for each model, and every reply says which model and effort it was written with: “Claude Code · Sonnet 5.5 · low effort”.

/model sonnet, /effort high and /assistant codex do the same from the message box.

Or ask for it

“Switch me to Claude Code with its default model, on high effort.” Unless you’ve said otherwise, it asks you first, then makes the switch when its reply is finished. The new conversation opens with a line saying what happened: “Claude Code is the writing assistant now (model Default, effort High), as you asked. This is a new conversation: your last one is kept with Codex, to carry on if you switch back.”

Why bring your own

You may already pay for one of these, and have chosen it. Foreword shouldn’t sell you another subscription, or tie your book to one company. These assistants also get better every few weeks, and when yours does, so does Foreword.

What it doesn’t do

  • Foreword has no AI of its own. The OpenCode that comes with it still needs an account with an AI company, or a model running on your Mac.
  • One assistant per window at a time. Switching starts a new conversation, and waits for the current reply to finish.
  • Gemini CLI and Antigravity haven’t yet been tested in a real signed-in conversation. Claude Code, Codex and OpenCode have.
  • Claude Code and Codex may need Node.js on your Mac, and Settings says so if it’s missing. The first start can take a minute.
