The five

OpenCode
Open source. Works with any AI you’ve set it up for: OpenAI’s, Anthropic’s, Google’s, or one that runs on your Mac. It still needs an AI to talk to.
Claude Code
Anthropic’s. Claude, with your Claude plan or an API key.
Codex
OpenAI’s. Its models, with your ChatGPT plan or an API key.
Gemini CLI
Google’s. Gemini, with a paid API key or a Gemini Code Assist work account. It doesn’t take personal Google accounts.
Antigravity
Google’s newer one: Gemini and more, with your Google account, a Gemini API key or Gemini Enterprise.

If you already have one of these on your Mac, and it’s new enough, Foreword uses yours. If you don’t, Install, in the chat or in Settings ▸ Assistant, puts in Foreword’s own copy, fetched from its maker: OpenCode from its own releases, Claude Code, Codex and Gemini CLI from their makers’ packages, and Antigravity from Google. It goes in Foreword’s own folder, and nothing else on your Mac changes. A copy you installed yourself is never touched, and Foreword keeps its own up to date as Foreword updates. Foreword itself doesn’t come with an assistant inside.

Settings ▸ Assistant shows where each one stands: Installed, Signed in with ChatGPT, Not signed in, Not installed. To sign in, Sign in in Terminal opens Terminal with the sign-in already started, and a note saying what to do. Come back to Foreword when you’re done and the assistant starts up on its own.

Whichever you choose, everything else on these pages works the same way: tasks, modes, questions, permissions, the account of what it did.

What Foreword changes

These assistants are built for writing software, and left to themselves they behave that way: they try to build the book, write scripts, and report their work as a programmer would. Foreword gives each one:

  • Instructions for a book, not a codebase, in place of the ones their makers wrote for programming (Antigravity has them added to its own). One sentence per line. Leave the typesetting to the preview. Say what changed in one to three sentences. Write maths as Typst maths. Don’t build tools around the book.
  • Your book’s style guide, in every conversation.
  • Foreword’s own modes: Write, Ask, Discuss, Options and Figures, enforced by Foreword.
  • The same question panel for all five, however each one likes to ask.
  • Every step in words about your book.
  • Your permissions, kept by Foreword, the same for every assistant.
  • A way to change Foreword’s settings, its model or which assistant it is, when you ask it to.

Model and effort

Under the message box: the assistant, the model, and how hard it thinks. Effort is how long the model thinks before it answers. More is slower, and usually better on hard requests. It matters about as much as the choice of model, so it has its own menu. Claude Code has Default, Low, Medium, High, Extra high and Max. Codex and OpenCode have their own levels. Foreword remembers the level for each model, and every reply says which model and effort it was written with: “Claude Code · Sonnet 5.5 · low effort”.

Switching mode keeps the assistant, model and effort you’re using. To Discuss with Claude Code and Write with Codex, say, pin Discuss to Claude Code: choosing Discuss then brings Claude Code back, and leaving it brings back your usual one. The mode menu shows what each pinned mode runs on, and the chat says when a switch changes it. When the chat moves to another assistant this way, it’s given the turns it hasn’t seen, so it knows what you’ve talked about.

In the bar under a selection, Revise, Options and Ask each show what their request will run on, beside the button that sends it, and you can change it there.

/model sonnet, /effort high and /assistant codex do the same from the message box, and /pin and /unpin pin the mode you’re in.

Switch halfway through a task

Choosing another assistant is like choosing another model: the chat stays where it is, and the task carries on. Start a task with Claude Code, switch to Codex for a second opinion, and your next message goes to Codex with the conversation so far, so it knows what you’ve talked about and what was changed. Switch back, and Claude Code picks up its own conversation, told only what was said since. The chat says which it is: “With Codex now: a new conversation, and the chat so far goes with your next message.”

Your tasks are all in one list, whichever assistant they were with. Open one, and it carries on with the assistant you’re using now.

Or ask for it

“Switch me to Claude Code with its default model, on high effort.” Unless you’ve said otherwise, it asks you first, then makes the switch when its reply is finished, and the task carries on. The chat says what happened: “Claude Code is the writing assistant now (model Default, effort High), as you asked, and this task carries on with it: a new conversation, and the chat so far goes with your next message.”

Why bring your own

You may already pay for one of these, and have chosen it. Foreword shouldn’t sell you another subscription, or tie your book to one company. These assistants also get better every few weeks, and when yours does, so does Foreword.

What it doesn’t do

  • Foreword has no AI of its own. OpenCode still needs an account with an AI company, or a model running on your Mac.
  • One assistant per window at a time. Switching waits for the current reply to finish.
  • Gemini CLI and Antigravity haven’t yet been tested in a real signed-in conversation. Claude Code, Codex and OpenCode have.
  • Installing one is a download, so it needs the internet, and its first start can take a minute.
