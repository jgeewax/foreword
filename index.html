Write in plain text. Watch it become a book.

Typst Studio is a Mac app for writing books, papers and picture books in Typst. The typeset pages update beside your words as you type, and a writing assistant reads, explains and edits with you, showing every change it makes.

Get started Source on GitHub

Live pages

The pages as they'll print, while you type

Typst Studio typesets the book from what you've typed, saved or not, and redraws only the pages in view. In a 491-page book, a change shows up in the preview in about a tenth of a second.

  • Click a passage in the preview to go to its source; move through the source and the preview follows.
  • An error is underlined where it is, and the assistant will explain it in plain words and fix it. Meanwhile the preview keeps the last good pages.
  • Export the PDF when you want it. Nothing to compile by hand.

A writing assistant

An assistant that edits, and shows its work

Select a passage and ask about it, or ask for a change. The assistant reads the chapters it needs, follows your book's style guide, and edits the files themselves. Its steps read as plain sentences, like “Read ‘Story of the Door’ (chapter 1)”, never as shell commands.

  • Lines it changed are marked beside the line numbers until you rewrite them; hover for what was there before.
  • Plan talks a change through before writing it. Options gives three versions of a passage to pick from.
  • You decide what it may do without asking: edit, rename, delete, or run a command.

History

Every version, and what changed in it

History saves a version as you work and around every assistant change, in a repository of its own, outside the book's folder. Open any version to see what changed, line by line or word by word, then undo just that change or put the whole book back.

  • Name a version, like “Draft sent to my editor”, to find it later.
  • Already keep your book in Git? Source Control stages, commits, pulls and pushes it.

Templates and samples

Novels, textbooks, picture books and papers

Start a book from a template: a novel, non-fiction, a textbook, a programming book or a picture book, at the page sizes printers use in the US, the UK and Europe, and Asia. Papers start from IEEE, ACM, NeurIPS, CVPR, AAAI, ACL, Springer LNCS, arXiv, AMS or APA.

Or open a finished sample and try the assistant on it: Jekyll and Hyde, Calculus Made Easy, The Elements of Style, The Tale of Peter Rabbit, Attention Is All You Need, and Counting Words, Python for writers, whose examples run.

Assistants

Bring the assistant you already use

The writing assistant is a program on your Mac, with your own account. Pick one in Settings, or from the chat, beside the model.

OpenCode

Open source

Any model you've set up in it: OpenAI, Anthropic, Google, or one running on your Mac.

Claude Code

Anthropic

Claude, with your Claude plan or an API key.

Gemini CLI

Google

Gemini, with a paid API key or a Gemini Code Assist work account.

Codex

OpenAI

OpenAI's models, with your ChatGPT plan or an API key.

Claude Code, Gemini CLI and Codex connect over the Agent Client Protocol. Each conversation is its own task, and several can run at once.

And more

Made for the whole job of a book

Review comments

Comment on passages as an editor would, then have the assistant address them, each change kept or undone on its own.

Code that runs

Examples in Python, JavaScript, R, Julia, Ruby, Lua, Perl and shell run from the book, with their real output set beneath and checked against what you expect.

Covers and printing

Design a print cover with the spine worked out from the page count, check the files against the printer's rules, and order through Mixam.

Your style, kept

A WRITING_STYLE.md for each book (voice, tone, terminology) that every request follows. The assistant can draft it from your chapters.

New to Typst?

Typst is plain text with a little markup. Typst basics opens beside your book and takes about five minutes; the assistant answers the rest.

Familiar keys

A command palette (⇧⌘P), Go to file (⌘P), tabs and shortcuts as in VS Code, formatting on save, and a window for each book.

Get started

Run it from source

Typst Studio is in early development, and there's no download yet. It runs on macOS (Apple Silicon first) and needs Xcode's command line tools (xcode-select --install), Rust, Node.js and Tinymist, which typesets the preview.

For the assistant, install one of OpenCode, Claude Code, Gemini CLI or Codex and sign in once. Settings ▸ Assistant says what each needs on your Mac.

# the tools
brew install rust node tinymist opencode

# the app
git clone https://github.com/jgeewax/typststudio.git
cd typststudio
npm install
npm run app
